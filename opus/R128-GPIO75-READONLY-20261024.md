Probe waits for the card, verifies 179:0/179:1, requests block read-only mode,
reads the first MiB eight times into RAM with a 12-second timeout per read,
and requires identical SHA256 and exact byte counts. It then mounts exFAT
ro,noatime and the image via losetup -r + ext4 ro,noload, avoiding journal
replay. It prints the Arch image marker, saves logs in RAM and starts shell.
It performs no fsck repairs, SD formatting, or automatic switch_root.
This tests basic read access only, not comprehensive card integrity.

GPIO75 enable and removal of automatic writes both change versus R127;
improved storage stability cannot be attributed solely to GPIO75 without
a same-probe comparison. If GPIO75 access resets, all other GPIOs remain
blocked, narrowing the failure compared with the old full-pin mask.
