# R127: reserve all TLMM GPIO lines

Status: microSD detected under 6.12; storage I/O unstable, Arch boot failed.

R126 stop=6 reached shell. The suspect interval starts at gpiochip_add_data
and includes subsequent consumers. Local gpiolib.c:1058-1067 initializes
every valid descriptor by calling gc->get_direction. The SM8250 callback
msm_gpio_get_direction reads each line's CTL register. R125 only reserved
GPIO40-43. A bad/secure line read is plausible, not yet proven.

R127 compares against the reset-producing R125 using EXACT original R118
Image (dbcffeead9750aa41228269f2101c32c76cbde42d1bea554db1132ad30eac11d),
original initramfs and original cmdline with no blacklist or stop gate.
Only the R125 DTB gpio-reserved-ranges changes from <40 4> to <0 181>.
TLMM remains enabled and GPIO75 hog remains disabled as in R125.
SM8250 driver ngpios=181; this excludes every GPIO from direction scanning
and also blocks GPIO consumers. It does not disable native SD pad pinconf.
