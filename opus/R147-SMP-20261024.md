# R147: all 8 CPUs on the R140 desktop

2026-10-24. Exact R140 payload (Image 03b2f152…, DTB 8890bca3…, initramfs cb68f767…);
only the kexec cmdline changed. Runner `scripts/test-r121-r147-smp.sh`.

## Result

- Try 1 appended `maxcpus=8 nr_cpus=8`: still 1 CPU. `nr_cpus=` can only
  lower nr_cpu_ids, so a later larger value is ignored once `nr_cpus=1` ran.
- Try 2 removed `maxcpus=1 nr_cpus=1` from the cmdline (runner refuses to
  run if any maxcpus/nr_cpus is left). Boot 966c3ebe-19f5-4c98-8ff2-56de661c361c:
  `smp: Bringing up secondary CPUs`, CPU1..7 booted (4x 0x51df805e Kryo silver,
  4x 0x411fd0d0 Cortex-A77 gold), online 0-7, systemd running, USB SSH up
  ~100 s after kexec (was ~125 s), no RCU stall/soft lockup/Oops.
- KDE Plasma (software QPainter, tty7) started via `scripts/r140-plasma-start.sh`.
- MMCX still held at 256.
