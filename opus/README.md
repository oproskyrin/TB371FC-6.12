# TB371FC: handoff для Opus

Состояние документа: 2026-08-29.

Это рабочий handoff по переносу Linux и графики на Lenovo TB371FC (SM8250,
Adreno 650, внутренняя панель 2944x1840). Начинать работу нужно с этого файла,
затем читать документы в таком порядке:

1. [CURRENT_STATE.md](CURRENT_STATE.md) — что сейчас установлено и какой
   незавершённый эксперимент сначала проверить/откатить.
2. [CONNECTION.md](CONNECTION.md) — SSH, поиск адреса, fastboot и сбор логов.
3. [WORKSPACE_WSL.md](WORKSPACE_WSL.md) — где проект, WSL, исходники и сборки.
4. [RELEASES.md](RELEASES.md) — проверенные образы и правила отката.
5. [GRAPHICS.md](GRAPHICS.md) — архитектура графики, уже доказанные результаты,
   неудачные направления и следующая рациональная серия тестов.
6. [LINUX612_KEXEC.md](LINUX612_KEXEC.md) — доказанная граница зависания 6.12,
   live-карта памяти, аппаратно подтверждённый r64 и следующий тест r65.
7. [WORKFLOW.md](WORKFLOW.md) — безопасный цикл изменения, сборки и проверки.
8. [OPUS_START_PROMPT.md](OPUS_START_PROMPT.md) — готовое стартовое задание
   для агента.

## Цель проекта

Практическая ближайшая цель — получить стабильный KDE Plasma без дрожания
панели запуска и экранной клавиатуры. Планшет уже загружает полноценный Arch
Linux ARM с KDE, Wi-Fi, SSH и вводом. На vendor-ядре 4.19 дисплей обслуживается
downstream SDE DRM, а Adreno 650 — отдельным KGSL. Это принципиальное
ограничение: нормальный единый DRM/Freedreno стек ожидается только после
доведения Linux 6.12+, но прикладное ускорение на 4.19 уже доказано.

## Главное правило

Не считать изображение на экране достаточным доказательством. Для каждого
изменения сохранять:

- точный образ и SHA-256;
- исходный commit/patch и конфигурацию;
- `uname -a`, `dmesg`, `journalctl --boot`, параметры KWin и Mesa;
- способ отката до запуска теста;
- физический результат: рабочий стол, шум, чёрный экран, перезапуск либо
  возврат в fastboot.

Не копировать приватный SSH-ключ в эту папку и не добавлять его в Git. Путь к
существующему ключу указан в [CONNECTION.md](CONNECTION.md).
